Every market

Skill = hit rate minus Betika's fair probability. Return = flat 1-unit singles at the price taken.

How the verdict is set

  1. Thin sample: fewer than 30 settled legs. Log it, don't build around it.
  2. Edge: return per leg above 0, so your skill beats Betika's margin. Prefer these legs.
  3. Margin eats it: return between −5% and 0. Skill may be real but too small for the price.
  4. Avoid: return below −5%. Leave off the ticket.

Each market row carries about ±3–5 points of uncertainty. Re-check after every collector run.
